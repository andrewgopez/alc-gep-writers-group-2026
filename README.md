# ALC GEP Writers Group · Winter 2026

A small website with photos from the last day of the semester and the GEP week, celebrating the Arts, Literature & Communication (ALC) Graduation Exhibition Project writers group.

## Pages

- `index.html`: Home, with the whole-class photo and a short personal note
- `photos.html`: The two GEP group photos
- `class.html`: The disciplines in the class, with a note at the bottom

## Files

```
index.html
photos.html
class.html
style.css        Shared styles for all pages
script.js        Dark mode toggle, shared by all pages
photos/
  class.jpg
  group_1.jpg
  group_2.jpg
```

Photo filenames are case-sensitive and must match the `src` in each HTML file exactly.

## Features

- Responsive layout (phones, tablets and desktops)
- Dark mode toggle (the choice is remembered in the browser)
- No names on the site; people are described by discipline only

## Privacy

The pages include a `noindex, nofollow` tag so search engines don't list them. Anyone with the link can still open the site, so only share it with the class.

## Hosting

Deployed with GitHub Pages from the `main` branch, root folder. The site is served at:

```
https://andrewgopez.github.io/alc-gep-writers-group-2026/index.html
```
